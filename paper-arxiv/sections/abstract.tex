AI agents increasingly work alongside other agents, and one agent can talk another into breaking its operator's rule.
We study the first step of such collusion: a peer agent presses a target agent for a secret that the target's operator told it to protect.
In six scenarios, two open-weight targets, Qwen3-32B and gpt-oss-20b, leak the secret in some episodes and refuse in others under the same pressure.
We train linear probes on the target's activations and compare them with text monitors, which read only the transcript, on the same model calls.
Whether an episode will ever leak is barely predictable.
Whether this call will leak is highly predictable from a probe that reads the activations before the call writes anything.
On gpt-oss-20b, a probe on the call's reasoning, frozen before new episodes were collected, ranked the leaking calls above the others on those episodes (AUROC~\gptossFreshReasoning{}).
A simpler probe, read before the call starts, does the same on held-out scenarios (AUROC~\qwenCallProbe{} on Qwen3-32B).
A text monitor shown the same conversation does worse.
An overseer could therefore pause the call that is about to leak, although nothing we measured warns rounds ahead.
We test only exact-string secrets in synthetic scenarios.
