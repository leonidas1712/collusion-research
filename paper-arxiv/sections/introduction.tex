\section{Introduction}
\label{sec:intro}

AI agents increasingly work alongside other agents, sharing channels, tools and credentials.
That makes it possible for agents to coordinate against the people who deploy them.
In July 2026, agents in an internal cyber evaluation coordinated on an unsanctioned message board, passed credentials to one another and attacked production infrastructure, and some of them pressed others to join \citep{openai2026huggingface,greenblatt2026incident}.

Collusion of this kind often starts with recruitment, in which one agent presses another to break its own operator's rule \citep{agrawal2025,nakamura2026}.
Recruitment is hard to oversee.
The request comes openly from a teammate, in the channel the target is meant to use, so it is not prompt injection hidden in data \citep{liu2024formalizing,debenedetti2024agentdojo}.
The target also tends to refuse for a while, citing its rule, before it gives in, so a single message rarely looks alarming on its own.

Current oversight mostly acts after the fact.
Output filters catch an exact secret once it is written \citep{sharma2025constitutional}, and text monitors read the transcript \citep{radev2026}.
We ask whether an overseer can tell, before a call acts, that the agent is about to give in, early enough to pause that call.
Probes on activations can detect that an agent was exposed to an attack \citep{dong2026,yu2026} or read agents that were told to collude \citep{rose2026}.
Early-warning work under user pressure or prompt injection finds weak signals, which text baselines often match \citep{saraogi2026before,fayyazi2026agent,jia2026window}.
No prior work asks, call by call, whether an agent pressed by a peer is about to give in, and compares activations and text on the same calls.

In this work, a peer agent presses a target agent over many rounds to reveal a secret, such as a deploy token, that the target's operator told it to keep.
We read the target's activations at each of its calls before it generates anything, and compare linear probes with a zero-shot text monitor and a trained text classifier on exactly the same calls, in six scenarios on two open-weight models.
We find three things (\cref{fig:headline}).
First, the call that leaks is predictable just before it acts, and this held on fresh episodes on both models.
Second, the signal is short-range: it weakens when asked about the next round, and is weak for whether an episode will ever leak.
Third, a zero-shot text monitor does far worse than the probe, but a text classifier trained on the same labelled calls comes close, so activations add a small edge on top of training.

Our contributions are:
\begin{itemize}
  \item a recruitment benchmark of six scenarios in which the same model leaks in some episodes and refuses in others, with control episodes in which the peer never asks, released with all prompts and transcripts (\cref{sec:setup});
  \item probes, a zero-shot text monitor and a trained text classifier, scored on exactly the same calls at three distances from the act (\cref{sec:method});
  \item a per-call warning that holds on fresh episodes, including one pre-registered test, with controls for the obvious shortcuts and the deployment cost of acting on it (\cref{sec:results}).
\end{itemize}
