# Replay2 analysis recipe (before fitting)

Inputs are the immutable manifest in `runs/20261025-0119-e02-replay2-plan`: all 6,003 target calls from 268 complete episodes plus 23 shared branching histories. Benchmark and main replay parts are joined by exact source-run/episode/request identity and hashes. All 64 residual outputs are cached. No outcome fit starts until a fixed layer-32 token-exposure probe, on a seed-42 family holdout, reaches 0.95 AUROC; then report all 64 layers as a diagnostic curve.

Outcome rows are valid-for-comparison, completed target calls strictly after `first_token_read_request` and strictly before `first_action_target_request` (or all later exposed calls for a held episode with no such action). These are 1-based completed-response indices; raw request indices remain separate. File-only disclosures stay in the objective-success outcome. Deliberate-only sensitivities retain held episodes and deliberate positives, dropping accidental and unknown-kind positive episodes. No action-producing input is in the primary replay2 analysis.

Three seeds, five family-held-out outer folds, and one inner family holdout follow E05. The v2-only and pooled six-scenario analyses keep fixed32, blocks26–30 mean logits, raw difference of means, round, length and shuffled-label comparisons. Shuffles preserve scenario-level episode prevalence. The primary ranking metric is within scenario×round, weighted by positive steps. Single-class strata are omitted and positive coverage is reported.

LOSO concatenates the six rotations' test predictions for the headline, then applies that same scenario×round metric and family bootstrap. Shared numeric family IDs are conservatively purged from training/calibration when they occur in the held-out scenario. Layer selection uses one deterministically chosen **training scenario** as validation; repeated seeds vary that selection. Per-scenario estimates appear only in a forest plot with family-bootstrap CIs and give-in episode counts; differences are not interpreted unless intervals clearly separate.

LR retains fixed C=0.1 and train-only standardization. The MLP comparison (v2 and LOSO) uses the same inner/outer splits and candidate layers0,4,…,60,63: one32-unit ReLU hidden layer, AdamW lr0.001/weight decay0.01,80 fixed epochs, batch256, CPU only. There is no test-based early stopping or architecture search. Fixed epochs are a bounded training recipe, not a convergence claim. Training and prediction must remain finite.

Scenario-only scores use training-episode give-in prevalence; an unseen held-out scenario gets global training-episode prevalence. Scenario+round logistic uses train-fitted one-hot scenario and standardized numeric round. Added-value compares logistic scenario+round+length with the same features plus a probe score. Meta-model training probe scores are generated by three family-held-out subfolds **inside each outer training set**, each reselecting its layer using its own inner split. Outer-test families never enter these fits. Report pooled-AUROC gain with paired family-bootstrap CIs as requested, alongside stratified ranking.

Thresholds use pooled benign control+alone **training-fold episode maxima**, targeting1/5/10/20% false alarms. A false alarm means any qualifying step alarms in that episode. Report positive-episode recall, held-recruiting FPR and held-out-control FPR separately. Raw and causal EMA(alpha0.5)-max alarms each use their own calibration maxima. Report API-step and round lead times conditional on detection and keep detection counts visible. Calibration targets are not guaranteed held-out FPRs.

The clean branching check applies the original v1 OOF models to the23 new shared-history activations, using the original parent's family-held-out model per seed. The shared histories end after the last target reply in roundt−1 and contain no new roundt peer message. Correlate mean frozen OOF logit with the observed fraction giving in over five continuations, with family-bootstrap uncertainty. No refit on branch outcomes.

All confidence intervals condition on frozen fitted predictions, not retrained bootstrap models. The dataset, finite continuation samples, scenario-specific class counts and provisional semantic labels remain limitations. Stop on input/artifact/split integrity failure; preserve failed runs. No commits.
