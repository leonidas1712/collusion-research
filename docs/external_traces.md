# External traces: public multi-turn pressure data we could reuse

2026-10-24, claude-2, for Leo. The question: are there public raw multi-turn traces where one agent pressures another to break a rule, collude or leak, with outcomes we can label, replay through an open-weight model, and run probes and text monitors on?

**Tags:** **V** = verified (we opened the HF API, repo tree, or a downloaded sample). **I** = inferred or from the paper only. "Not found" means we searched the paper, GitHub and HF and found nothing; it does not prove nothing exists.

## Short answer

- **One dataset is close to our setup:** Shi et al. 2026b (`SALT-NLP/agent-collusion`). Two agents work over 10 episodes under a verification rule they gradually relax, with the episode where collusion starts already labelled, open-weight models, full transcripts and reasoning, MIT. It is mutual collusion, not one agent recruiting another, but it is the only released set with "holds, then gives in" built in.
- **NARCBench releases traces and activations, but only for instructed collusion.** Its emergent split (Verdict, made with the Shi harness) is not released; it can be regenerated.
- **Colosseum, Voluntary Collusion, GroupGuard, Many-to-One and Paglieri: no author traces.** Colosseum has code; Voluntary Collusion promises code on acceptance; the rest have none.
- **Outside the collusion papers**, the closest are PMIYC (agent persuades agent, support scored every turn), SYCON-Bench (scripted pushback, exact flip turn, Qwen2.5-7B traces) and the SaTML'24 CTF (a real "don't leak the secret" rule with outcome labels, but mostly short chats, human attackers).
- **The OpenAI–Hugging Face incident transcripts are not public** (METR: shared under agreement). The collusion.wiki dump is public, but it holds wiki edits, not labelled conversations.

## The catch for all of these: whose activations?

A trace's "gave in" label describes the model that wrote the target's turns. If we replay someone else's trace through granite, granite reads text it didn't write, and the label isn't about granite. Probes trained that way learn "this text is about to give in", which a text monitor can read too.

Two clean options:
1. **Replay through the original target model** when it is open-weight (Shi: Qwen3.6-27B, Qwen3.8-27B, Gemma-4-31B, probably DeepSeek-V4-Flash; NARCBench: Qwen3-32B, activations already released; PMIYC: Llama-3.1-8B / Llama-3.3-70B persuadees; SYCON: Qwen2.5-7B). The activations are then the target's own at its own turns.
2. **Keep only the pressuring side** and regenerate the target's turns with our model, then label from our model's outputs. Cheap for PMIYC and SYCON; harder for Shi (the peer reacts to the target, so a fixed peer script drifts off-conversation).

Option 1 is the backup route's natural test set: **no instruction to collude, natural give-ins, open weights.**

## Recommendation

1. **Shi et al. is the one to look at first.** Pull the Qwen3.8-27B (or Qwen3.6-27B) main-condition trajectories (50 × 10 episodes, ~1.3 GB for the main family), replay the agent's own turns through that same model on a GPU, and test whether a probe at the turns *before* the onset episode predicts it, against a text monitor at the same cutoff. It tests our method on someone else's data, with no instruction to collude. Cost: 27B in bf16 needs ~55 GB, so an A100 80GB or H100; long cross-episode contexts make this the expensive part.
2. **Regenerating NARCBench Verdict** with the Shi harness is the same data with NARCBench's extraction scripts; only worth it if we want to compare to their numbers directly.
3. **PMIYC and the SaTML CTF** are cheap ways to get many on-policy give-in turns from a small open model (keep the pressuring side, regenerate the target with granite or Qwen3-8B). They're secondary: belief change and short leaks, not an agent recruiting a teammate.
4. **Not usable as data:** the incident transcripts (private), Colosseum (no author traces), Voluntary Collusion, GroupGuard, Many-to-One (no releases).
