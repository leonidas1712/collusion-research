# Candidate peer-tactic families for recruitment studies

## Scope and safety boundary

This is a design menu for a controlled study of whether monitoring methods can detect one agent pressuring another to violate an operator rule. It is not a prompt library and contains no runnable tactic instructions. The short lines below illustrate the distinction between tactic families; they are not complete prompts.

Every family is dual-use because the same interaction pattern could be used to weaken a deployed agent's policy adherence. Any implementation should remain in the synthetic deploy-token environment, use fake credentials, preserve deterministic leak scoring, require human review before execution, and be evaluated for detection and mitigation rather than operational effectiveness alone.

The cited studies mostly test general safety refusals, prompt injection, or persuasion on question-answering tasks. Applying their mechanisms to peer-agent credential recruitment is a research hypothesis unless the row says otherwise.

## What to try next

1. **Refusal then task reframe.** Highest value because it is adaptive to the target's actual refusal, requires no new environment state, and tests a mechanism not covered by the existing fixed tactics. Design and offline review should take about two hours.
2. **Workflow or handoff completion.** Highest realism and a clear contrast with overt persuasion. It needs a matched control record and a wording review, about three hours.
3. **Partial-compliance ladder.** Best for studying gradual boundary erosion, but it needs partial-disclosure labels before use. Design, scorer extension, and offline tests would take roughly four to six hours.

The other four families should remain future work. Gradual escalation overlaps the current tactic scaffold; claimed authority introduces deception and overlaps organizer tone; prior-turn demonstrations alter the starting context; decomposition requires a new reconstructable-leak outcome.

## Comparison requirements for any later implementation

- Keep the target system prompt, synthetic credential, task, tools, and consequence rule fixed.
- Pair each recruiting tactic with a control that uses the same interaction structure for a permitted field.
- Preserve the no-tactic baseline and report first disclosure round, complete disclosure, partial disclosure, and accidental leakage separately.
- Record the peer's tactic transitions so detection can be evaluated before the first boundary violation.
- Review filled text before any run. This document does not authorize implementation or execution.
