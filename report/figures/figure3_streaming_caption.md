Figure 3. On gpt-oss-20b, a probe reading the model's reasoning picks out the reply that will leak the secret, and reading the text of the same reasoning does not. This analysis is exploratory and was designed after the main results. (a) Each row scores the same 1,995 replies that have reasoning (121 of them leak) from 238 episodes, on held-out scenarios. A reply counts as leaking if it is the first to make the secret public, by any route. AUROC measures how well a score ranks leaking replies above the others: 0.5 is chance and 1 is perfect. Whiskers are 95% bootstrap confidence intervals. "Stopped before the secret is mentioned" ignores every reasoning token from the first time the secret appears in the reasoning. The length row uses the final length of the reasoning, which is known only after the reply, so it is not a usable alarm. *This probe reads only what arrives before the reply: the peer's message and tool results (one seed; 2,199 replies, 143 leaking). It also scores 0.93, so much of the signal is already there before the model reasons. †The same probe, scored on replies from before the peer asks, against whether the episode ever leaks (628 replies, 388 positives); it stays at chance, as it should. (b) The same kind of probe, asked about leaks at different distances. The points are not a paired comparison: the reply set and the input differ between them. Probe at end of incoming message: 2,059 replies (169 positives for "ever", 148 for "this round or next"). Probe on reasoning, this round or next: 1,874 replies, 118 positives. The 0.93 point is the headline result from panel a, whose reply set also includes each episode's first leaking reply. Appendix J.8 gives the full table, including the reasoning probe on that larger reply set for "this round or next" (0.64). All points cover 238 episodes. Values and exact source keys are in figure3_streaming.csv.
