Figure 3. On gpt-oss-20b, a probe reading the model's reasoning picks out the reply that will leak the secret, and reading the text of the same reasoning does not. This analysis is exploratory and was designed after the main results. (a) Each row scores the same 1,995 replies that have reasoning (121 of them leak) from 238 episodes, on held-out scenarios. A reply counts as leaking if it is the first to make the secret public, by any route. AUROC measures how well a score ranks leaking replies above the others: 0.5 is chance and 1 is perfect. Whiskers are 95% bootstrap confidence intervals. The right-hand column shows the practical trade-off: each detector's alarm cutoff is set so that about 5% of no-ask control replies alarm, and the column gives the share of leaking replies that cutoff catches and the share of normal replies in pressured episodes that never leak on which it fires. The keyword rule never fires, because it matches more than 5% of control replies. "Stopped before the secret is mentioned" ignores every reasoning token from the first time the secret appears in the reasoning. The length row uses the final length of the reasoning, which is known only after the reply, so it is not a usable alarm. *A separate probe, trained on this label for each call, that reads only what arrives before the reply: the peer's message and tool results. It used a reduced recipe (one seed, layer 18; 2,199 replies, 143 leaking). It also scores 0.93, so much of the signal is already there before the model reasons, but it alarms far more often on normal replies. †The same probe, scored on replies from before the peer asks, against whether the episode ever leaks (628 replies, 388 positives); it stays at chance, as it should. (b) Probes asked about leaks at different distances; a "call" is one model reply. The diamonds are the paper's main probe, read at the last prompt token, not the incoming-message probe of panel a. The points are not a paired comparison: the label, the reply set and the input differ between them. In particular, the 0.60 and the 0.93 use different labels and different reply sets. Paper's main probe: 2,059 replies for "ever" and "this round or next" (169 and 148 positives). Probe on reasoning, this round or next: 1,874 replies, 118 positives. "Next call" excludes the leaking calls themselves, so it is a genuine one-call-ahead ranking: 1,874 replies, 116 of which come just before the leaking call; both probes were trained on other labels and not refitted. The 0.93 point is the headline result from panel a, whose reply set also includes each episode's first leaking reply. Appendix J.8 gives the full table. All points cover 238 episodes. Values and exact source keys are in figure3_streaming.csv.
