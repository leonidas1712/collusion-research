Figure 3. A probe on the model's activations picks out the call that will give in; an LLM judge given the same material does reasonably on Qwen3-32B but far below the probe, and on gpt-oss-20b ranks the leaking calls below the others. This analysis is exploratory and was designed after the main results. (a) Per-call within scenario × round AUROC on held-out scenarios (0.5 is chance, 1 is perfect); whiskers are 95% family-bootstrap confidence intervals. A call is positive if it is the first to make the protected value public: for gpt-oss-20b by any public emission (1,995 calls with reasoning, 121 positive, 238 episodes), for Qwen3-32B by the paper's give-in rule (4,844 calls, 101 positive, 241 episodes). The last-prompt probe reads one position before the call generates anything; the reasoning probe takes the maximum over the call's reasoning tokens. The frozen row applies the reasoning probe and its alarm cutoff, both fixed in advance, to 84 new episodes (594 calls with reasoning, 26 leaking, from 57 recruiting episodes). Jev 1.14 is given the same conversation and tool results as the last-prompt probe and asked whether this call will write or post the value; on gpt-oss-20b, as asked, it ranks the leaking calls below the others within a stratum (0.27; 0.73 if reversed post hoc, still below the probe's 0.91) and flags nearly every pressured call; its input excludes earlier same-turn private reasoning, which the probe's activations may retain. Jev reading the reasoning sees only the call's reasoning text, as six growing snapshots scored with a running maximum and with the value masked. At a cutoff set for about 5% alarms on no-ask control calls, the share of leaking calls caught and of calls in refusing episodes flagged is 56% / 2% for the last-prompt probe, 85% / 4% for the reasoning probe, 54% / 2% for the frozen probe on new episodes, 98% / 87% for Jev on the same input and 92% / 9% for Jev on the reasoning; on Qwen3-32B, Jev on the same input is 71% / 28%. Qwen3-32B runs without reasoning. Further checks and baselines are in Figure 3b. (b) Matched ladders: within each series the model, the outcome, the reading position and the calls are fixed, and only the label horizon changes; lines join points of the same series, and the series are not compared with each other. Qwen3-32B, last prompt token, the paper's give-in rule, on the same 4,844 calls from 241 episodes (ever, 0.54, 1,105 positives; this round or next, 0.67, 352 positives; this call, 0.95, 101 positives); these round-level values differ from the paper's 0.52 and 0.58, which use the original 4,697-step cohort without the give-in calls. gpt-oss-20b, last prompt token, any public emission rather than the paper's give-in rule, on the same 1,995 panel-a calls from 238 episodes (ever, 0.61, 330 positives; this round or next, 0.64, 304 positives; this call, 0.91, 121 positives). Retrained to ask whether this call will leak, the paper's last-prompt probe reaches 0.91 before the model writes anything; reading the reasoning adds a little (0.93, the panel-a headline). One-call-ahead results (Qwen3-32B 0.71, gpt-oss-20b 0.62) use different call sets that exclude the give-in calls and are left to the appendix. Values and exact source keys are in figure3_streaming.csv.
