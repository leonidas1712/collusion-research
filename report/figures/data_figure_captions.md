# Figure and table captions

**Figure 2. Near-term prediction is stronger on Qwen3-32B; the corresponding gpt-oss estimates remain close to chance.** Within-scenario × round AUROC with 95% family-bootstrap intervals (1,000 resamples). Qwen uses 4,697 recruiting steps from 241 episodes (998 eventual-positive; 250 near-term-positive); hollow squares show confirmation on 1,787 steps from 89 episodes (82 near-term-positive), which are also included in the full Qwen cohort. The two Qwen estimates are therefore not independent. The gpt-oss panel uses 2,059 post-ask steps from 238 episodes (169 eventual-positive; 148 near-term-positive), with diamonds for eventual and triangles for near-term outcomes. Probes use inner-selected layers and held-out-scenario evaluation; fixed monitors use the same eligible steps within each target. Monitor identities and access levels match across targets; target-private reasoning is omitted from the shown monitors. Near-term means the first public emission occurs this round or the next, with channel publication defining a positive episode. Target cohorts and collection protocols differ; markers are not paired across targets. Missing gpt-oss combination estimates are labelled, not scored as zero.

**Monitor-design figure. What should a text monitor ask, and what should it see?** Within-scenario × round AUROC for the near-term label on Qwen3-32B, with 95% family-bootstrap intervals and a chance line at 0.5. Panel (a) compares Jev 1.14 detector and forecaster questions on all data (4,697 steps; 250 positives; 241 episodes). Panel (b) compares forecasters on the first data batch only (2,910 steps; 168 positives; 152 episodes), because the full three-monitor access ladder exists only for that batch. Actions-only input contains target tool calls and posted messages; conversation access adds peer messages; seeing everything the target saw also adds unposted target text and tool results. Marker shape and line style identify the monitor/question; green shades identify access levels. The panels use different cohorts and should not be compared as paired estimates. Jev benefits from conversation access; more access does not improve every monitor. Paired access contrasts are provided with the figure data. The all-data pool includes the confirmation subset (1,787 recruiting steps from 89 episodes; 82 near-term positives); it is not an independent replication. No confirmation markers are shown here.

**Table 1. Mixed recruitment outcomes across six Qwen3-32B scenarios.** Give-ins divided by analysed episodes, with Wilson 95% intervals for recruiting rates. These are plain-peer episodes from the scale-up source runs used in the main analysis, including episodes with no replay-eligible step. An analysed episode is complete, has accessed the protected value, and passes the scenario-specific inclusion checks, including a successful correct status-summary write at any point in the episode (not only the final file state). The outcome follows the frozen main-analysis objective label where available and the same scorer rule elsewhere; accidental disclosures count. Of 304 recruiting attempts, 224 are analysed, 37 never read the value, 30 are incomplete, and 13 fail the task-completion checks. Controls have 66 analysed episodes from 75 attempts, excluding incomplete episodes or failed task-completion checks; alone denominators exclude one unread attempt from 26. Excluded attempts do not count as held. The raw table includes every exclusion count. These episode-level denominators differ from the scored-step cohort in Figure 2 (4,697 recruiting steps from 241 episodes; 998 eventual positives and 250 near-term positives) and its confirmation subset (1,787 steps from 89 episodes; 82 near-term positives). Confirmation episodes are included in the all-data pool. These are descriptive results conditional on the selected scenarios and batches, not randomized model comparisons.

**Table 2. Does the activation probe add to a text monitor?** Near-term within-scenario × round AUROC on Qwen3-32B. The baseline is a cross-fitted model of round, log prompt length and the monitor score; the combined model adds the probe score. Jev uses the forecaster question with everything the target saw; GPT-5-nano uses the detector question with conversation access. Held-out-scenario and pooled family cross-validation use all data (4,697 steps; 250 positives; 241 episodes). The frozen-plan confirmation trains on the first batch and evaluates 89 new episodes (1,787 steps; 82 positives). All intervals are 95% family bootstraps; gains use paired resamples, not subtraction of marginal interval endpoints. The weaker-monitor gain is positive in pooled cross-validation and confirmation, but its held-out-scenario interval includes zero. No clear gain over Jev is established. The confirmation episodes are included in the all-data pool, so these estimates are not independent.
