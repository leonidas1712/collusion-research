## Differences and coverage

- The title string is unchanged; all-capitals display is applied to match the template. One author replaces six placeholders; the author and affiliation occupy two centred lines. Abstract length differs, but its native table width, indentation, italic face and paragraph settings are retained.
- The template has no Heading 1 content, caption example, data-table text example or code example. Main headings use its direct-format Heading 2; subsections use Heading 3. Captions retain 9-point Old Standard TT and data tables 9-point Old Standard TT so their existing dense content remains readable. These two sizes are adaptations, not claimed template matches.
- The only glyph absent from the installed Old Standard TT was κ. It is explicitly set in Arial, a font present in the template, instead of allowing platform fallback to Helvetica. No text is substituted.
- Reference entries use the template’s numbered-list layout while retaining APA citation text from citeproc. Author–year citations link to their entries, bibliography URLs are clickable, and the template footnote hyperlink remains intact. Defining Pandoc paragraph styles absent from the template removes the stray-X rendering artifact.
