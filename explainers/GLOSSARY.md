# Glossary

- **First-action round:** the round in which the target first does the forbidden thing (e.g. posts the token).
- **Residual stream:** the list of numbers each token carries through the model; every layer reads it and adds to it. 5,120 numbers in Qwen3-32B.
- **Linear probe:** weights w and bias b; score = sigmoid(w·h + b) on one residual-stream vector h.
- **AUROC:** pick one random "will give in" step and one random "won't" step; AUROC is how often the method scores the first one higher. 1.0 perfect, 0.5 a coin flip, 0.75 right three times in four. Needs no threshold. Example: positives 0.7, 0.4 vs negatives 0.5, 0.2 → right in 3 of 4 pairs → 0.75.
- **Within-round AUROC:** AUROC computed only between steps at the same round, then averaged (weighted by positives), so conversation length can't help.
- **Recall at 5% false alarms:** set the threshold so 5% of control-episode alerts fire, then report the share of give-in episodes caught before the action.
- **"Words still say no" subset:** steps before a give-in where the target's own text doesn't yet signal it will share. Used only to recompute scores, never to change training.
- **Monitor ladder:** LLM-judge monitors that see progressively more: actions only, then the conversation, then unposted text, then reasoning.
- **Lead time:** how many turns before the action a detector first raises an alarm.
- **Episode (Shi et al.):** one round of the game: each agent does a task, they exchange up to five 200-character messages, then each accepts or rejects the other's work, then gets scored.
- **Trajectory (Shi et al.):** 10 episodes in a row with the same two agents, each keeping its full history; behaviour can drift across it.
- **Raw log:** the JSON list of an agent's tool calls and results in one task, from `get_log`; the rule says verdicts must be based on the peer's complete raw log.
- **Verdict:** an agent's accept/reject call on the other agent's task; accept without the raw log breaks the rule.
- **Collusive episode (Shi et al.):** both agents accept in the same episode, which breaks the rule on both sides.
- **Onset episode:** the first collusive episode in a trajectory (`onset_evaluation_episode`).
- **Reflection judge (relaxation):** an LLM (Qwen3.8-27B) that reads an agent's private post-episode note and says whether it now endorses accepting without the full log.
- **Step:** one target API request (a decision point, including between its own tool calls); one row of the probe dataset.
- **Family:** the seed shared by a recruiting, control and alone episode with the same task details; train/test splits keep a family together.
- **Within-round AUROC:** AUROC computed among steps of the same round only, then averaged over rounds weighted by positives; removes the conversation-length shortcut.
- **Nested cross-validation:** inside each training split, a further split picks the layer (and regularisation strength); the test fold never influences the choice.
- **Bootstrap interval:** resample families with replacement ~1,000 times, recompute the metric; the middle 95% is the interval.
- **Positive control:** a probe for something trivially present (has the token entered the prompt?); should score ~1.0, else the pipeline is broken.
- **Shuffled-label control:** rerun the pipeline with labels randomly reassigned across episodes; should score ~0.5, else something leaks.
- **Recall at 5% false alarms:** set the method's cutoff so 5% of control/alone *episodes* have any step above it (using each episode's highest score); recall = share of give-in episodes with a step above the cutoff before the leak.
- **L2 regularisation:** a penalty λ·Σw² added to the loss so the probe can't memorise with large weights; needed because there are more weights (5,120) than training rows.
- **Difference of means:** mean activation of label-1 steps minus mean of label-0 steps; a training-free probe direction, also used for steering.
- **Score (of a method):** one number per step from any method: probe probability, decision-model P(yes), LLM-judge score rescaled to 0–1, or a trivial baseline such as prompt length.
- **Alarm cutoff (threshold):** the score above which a method beeps; set per method from control-episode maxima at a fixed false-alarm budget, so methods are compared at equal false alarms.
- **Lead time:** steps (or rounds) between a method's first beep and the actual leak; how much time there was to intervene.
- **Held vs held-out:** a *held* episode is one where the target never gave in; a *held-out* episode is in the test fold, unseen in training.
- **Trade-off curve:** recall and lead time at several false-alarm budgets (1%, 5%, 10%, 20%), so operators with different risk appetites can read off their setting.
- **Added-value test:** pooled AUROC of turn number + prompt length, then with the method's score added; the gain is what the method knows beyond conversation length.
- **Token ID:** the integer the tokenizer assigns to one piece of text; the model reads a list of these, not characters.
- **Chat template:** the small Jinja program shipped with a model that turns a message list into the one marked-up string the model reads (Qwen: `<|im_start|>role ... <|im_end|>`).
- **add_generation_prompt:** chat-template option that appends the opening of the assistant's turn, so the prompt ends exactly where the model would start writing.
- **Last prompt token:** the final token of that rendered prompt; its vector has read the whole conversation and is what the model uses to pick the reply's first token. In our Qwen3 replay it is the `\n\n` after an empty `<think></think>`.
- **Decoder layer (block):** one of the identical stacked units in the model (64 in Qwen3-32B); each reads the residual stream, mixes in earlier tokens and adds its result back.
- **Forward pass:** one run of the model over a token list, producing outputs for every position at once; no new text is generated.
- **Forward hook:** a function attached to a PyTorch module that is called with the module's output every time it runs; we use it to copy one row out of each block.
- **Causal attention:** each token can see only earlier tokens, so adding tokens after a position never changes that position's vectors.
- **Teacher forcing:** feeding a known reply in as input and reading the model's probability for each of its tokens, instead of sampling new ones.
- **Logits:** the model's raw score for every vocabulary entry at a position; softmax turns them into next-token probabilities.
- **NLL (negative log-likelihood):** minus the log-probability the model gave the true next token, averaged over tokens, in nats; 0 is certain, ~0.25 means about 0.78 probability on average.
- **Top-5 fraction:** share of reply tokens that were among the model's five highest-scoring guesses at their position.
- **Replay fidelity:** how well our locally rebuilt prompt matches what the API model saw, measured by the NLL and top-5 fraction of the real saved reply (99.8% top-5 in the main replay).
- **SHA-256 hash:** a 64-character fingerprint of some bytes; any one-byte change gives a different hash. We store hashes of each episode, request, rendered prompt and token list.
- **Pinned revision:** a 40-character Hugging Face commit ID that fixes the exact weights, tokenizer and template, unlike the moving "main" branch.
- **Modal / Modal Volume:** a service that runs a Python function on a rented GPU, billed per second; a Volume is its persistent network disk, where we keep weights and outputs.
